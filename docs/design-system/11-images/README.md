## Regras canônicas

- PÁGINA = canvas da marca; IMAGEM = elemento visual isolado.
- Preferência: (1) line art ou figura vetorial; (2) recorte (cutout) com espaço negativo; (3) foto completa só quando a cena é a informação (CONF-007).
- Sem foto full-bleed como fundo, sem texto sobre foto ruidosa.
- Acento seletivo de cor só na região que importa.
- `alt` sempre; `caption` em evidência ou dado; `source` quando externo.
