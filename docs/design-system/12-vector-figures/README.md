## Regras canônicas

- 80–95% neutro (preto, cinza, branco).
- Azul = marca ou ativo; verde = solução; vermelho = risco; amarelo = GAP-005.
- Prioridade: posição, escala, peso, contraste e, por último, cor.
- Sem rainbow charts.
