# CONFLICT-REGISTER

Cada conflito lista os valores, as fontes, a precedência e a decisão. Nenhum foi resolvido em silêncio.

**Ordem de precedência.** Vem da proposta de `source/00-governanca/DECISIONS.md` e foi confirmada pelo usuário em 2026-10-07:

1. **Fundamentos aprovados.** BRAND-COLOR-SYSTEM para cor.
2. **Contratos editoriais.** MDX-CONTRACT, BLOCKS-CONTRACT e LEITURA-COGNITIVA para leitura.
3. **Sistemas de linguagem visual.** EDITORIAL-LAYOUT, CARD-HIERARCHY, VECTOR-FIGURE, INFOGRAPHIC e IMAGE-ILLUSTRATION.
4. **Handoffs, só por superfície e só para o que os itens 1–3 não cobrem.** Developer handoff, handoff editorial e storyboard.
5. **Referências externas.** São inspiração e nunca valem como regra. OBRAND-STYLING-001 e `01-referencias/visuais`.
